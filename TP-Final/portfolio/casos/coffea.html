Caso de estudio, 2026

Coffea

Landing de una cafetería ficticia, resuelta solo con HTML y CSS.

Ver el repositorio
Rol
Maquetado y front-end
Alcance
Landing y página 404
Stack
HTML5 y CSS3, sin JavaScript

Problema

El trabajo pedía llevar una landing a código sin JavaScript, frameworks ni preprocesadores. Carruseles, menú y favoritos normalmente dependen de scripts.

Proceso

Separé los estilos en capas y un archivo por componente, con nombres BEM y tokens para colores, fuentes y espacios. Trabajé mobile-first con breakpoints en 768, 1024 y 1440 px.

Solución

  • Carruseles con scroll-snap.
  • Menú mobile con el elemento details.
  • Favoritos con un checkbox y estilos por estado.

Resultado

La landing quedó publicada desde el repositorio con su página 404. También corregí errores de escritura que traía el diseño.

Aprendizaje: los elementos nativos resuelven más de lo que parece, y una estructura ordenada de CSS facilita cada cambio.
